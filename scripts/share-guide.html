Installation guide · @VERSION@

Airplay Flixer

Mac @CHIP@ · macOS @MACOS@ or later · Google Chrome

1

Open the Mac companion

Move Airplay Flixer.app to Applications, then open it from there. Its icon appears in the menu bar. Allow local network access if macOS asks.

This build is locally signed and has not been notarized by Apple. If macOS asks for confirmation, follow Apple’s instructions only if you trust the person who sent you the app. Read Apple’s guidance.

2

Load the Chrome extension

Keep the Chrome Extension folder in a permanent location. Open chrome://extensions, enable Developer mode, click Load unpacked and select that folder. Pin Airplay Flixer in the toolbar.

3

Choose your TV

In Playback, click the destination, select Search for devices and save your device as the default. If your Apple TV requests pairing, select Pair this Apple TV and enter the code shown on the TV. Reload the video page, start playback and open the extension to cast.

For advanced video features

HLS downloads, subtitle synchronization and some video formats require FFmpeg. If you use Homebrew, install it with brew install ffmpeg.

The Mac and Apple TV must be on the same local network. Your settings and pairings are created on your Mac at first launch.
